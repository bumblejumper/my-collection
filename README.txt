MY COLLECTION — iPHONE EDITION

Contains 1,697 movie catalogue rows preloaded on first use. Games and CDs are empty.

Open index.html using a stable HTTPS static host in Safari to reliably use localStorage. Opening via Files or file:// may not persist data. Hosting the app files does not upload your collection.

If you previously used the original app on the same website origin, its saved data takes priority; use the bundled CSV to import these titles, taking care to avoid duplicates.

Export Backup JSON regularly, preferably to Files/iCloud Drive. Browser data may be lost when clearing Safari website data or switching phones.

Metadata is taken from the supplied CSV and has not been independently verified. Estimated values default to £0 (unknown), not appraised values.
